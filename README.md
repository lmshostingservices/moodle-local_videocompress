# local_videocompress

## Summary

Zero-config automatic video compression.

## Description

Zero-config automatic video compression. All videos over 1MB are compressed to 720p to maximise storage savings while maintaining viewable quality.

## Current Release

Version 1.2.6 republishes the reviewed authoritative source under a new immutable tag because the historical tag contained a different source tree. There are no functional changes in this release.
